# GreenBite — Landing Page for Healthy Food Delivery Service

A modern, responsive single-page landing for a healthy food delivery service. Built with pure HTML, CSS, and vanilla JavaScript — no external libraries or frameworks.

## ✨ Features

- **Hero section** with offer, CTA buttons, and animated stats
- **Advantages** section highlighting key benefits
- **Menu / Catalog** with interactive category filter tabs
- **How it works** step-by-step section
- **Testimonials** from satisfied customers
- **Lead form** with validation and success state
- **Footer** with navigation, contacts, and social links
- **Scroll reveal animations** using IntersectionObserver
- **Fully responsive** design (mobile, tablet, desktop)
- Calm **blue + white** color scheme with **orange** accent

## 🚀 Quick Start

Open `index.html` in any modern browser, or serve it locally:

```bash
# with Python
python3 -m http.server 8000

# or with Node
npx serve .
```

## 🛠 Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid, animations)
- Vanilla JavaScript (IntersectionObserver, DOM manipulation)
